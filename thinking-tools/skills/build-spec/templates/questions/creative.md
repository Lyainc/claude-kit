# Build Spec — Creative Domain Question Bank

Use these as the basis for Phase 1 interview questions in creative projects.
Select the most relevant question per dimension per round. Adapt to user's specific context.

## Goal Clarity

- 이 작품/콘텐츠/프로젝트를 통해 어떤 경험을 전달하고 싶나요?
- 주요 독자/시청자/사용자는 누구인가요?
- 이것이 완성됐을 때 어떤 감정이나 반응을 기대하나요?
- 기존에 비슷한 작품이 있나요? 어떤 점에서 달라야 하나요?
- 핵심 메시지 한 문장으로 표현한다면?

## Constraint Clarity

- 형식/포맷 제약이 있나요? (길이, 장르, 매체, 플랫폼)
- 톤/보이스 제약이 있나요? (공식적/캐주얼, 유머/진지)
- 브랜드 가이드라인이나 스타일 가이드가 있나요?
- 완성 기한이 있나요?
- 예산이나 리소스 제약이 있나요?
- 사용할 수 없는 주제, 표현, 참조가 있나요?

## Success Criteria

- 어떤 반응이 오면 성공이라고 할 수 있나요?
- 최소 완성 기준은 무엇인가요? (초안? 완성본? 퍼블리시?)
- 검토자나 의뢰인의 승인 기준이 있나요?
- 측정 가능한 성과 지표가 있나요? (조회수, 공유수, 참여율)
- 이 작품이 "좋다"고 판단하는 사람은 누구이고 어떤 기준으로 판단하나요?

## Context Clarity (brownfield)

- 기존 콘텐츠 시리즈나 브랜드 자산에 연결되나요?
- 기존 스타일과 일관성을 유지해야 하는 부분이 있나요?
- 기존 에셋(이미지, 음원, 텍스트)을 재사용할 수 있나요?
- 이 작품이 들어갈 기존 플랫폼이나 채널의 특성은 무엇인가요?
- 기존 독자/팬층이 있다면 그들의 기대는 어떻게 되나요?
