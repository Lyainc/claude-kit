# Build Spec — Biz Domain Question Bank

Use these as the basis for Phase 1 interview questions in business/product projects.
Select the most relevant question per dimension per round. Adapt to user's specific context.

## Goal Clarity

- 이 이니셔티브가 해결하려는 비즈니스 문제는 무엇인가요?
- 이것을 통해 누가 혜택을 받나요? (고객, 내부팀, 파트너?)
- 현재 상태(AS-IS)와 목표 상태(TO-BE)를 비교해 설명해주세요.
- 이 프로젝트를 하지 않으면 어떤 일이 생기나요?
- 가장 중요한 성과 지표 하나를 고른다면?

## Constraint Clarity

- 예산이나 리소스 제약이 있나요?
- 일정 마감이 있나요? (규제, 이벤트, 계약 등)
- 이해관계자 승인이 필요한 결정이 있나요?
- 법적/규제 제약이 있나요? (GDPR, 내부 정책 등)
- 기존 프로세스나 계약에서 변경이 어려운 부분이 있나요?

## Success Criteria

- 3개월 후 이 프로젝트가 성공했는지 어떻게 알 수 있나요?
- 구체적인 KPI 목표가 있나요? (예: 전환율 5%p 향상)
- 이해관계자가 "성공"이라고 판단하는 기준은 무엇인가요?
- 최소 성공 기준(MVP)은 무엇인가요?
- 실패 시나리오를 어떻게 정의하나요?

## Context Clarity (brownfield)

- 기존 시스템/프로세스 중 이 변경에 영향받는 것은 무엇인가요?
- 현재 이 문제를 해결하기 위해 어떤 임시방편을 쓰고 있나요?
- 이 변경을 알아야 하는 내부 팀이나 외부 파트너가 있나요?
- 기존 데이터나 히스토리를 마이그레이션해야 하나요?
- 변경 후 기존 사용자 교육이나 적응 기간이 필요한가요?
