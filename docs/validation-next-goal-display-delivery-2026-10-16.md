## 확정한 계약

- 원본이 있는 후보는 짧은 포인터를 쓰고, 원본 없는 session/backlog 후보는 전문을 유지해요.
- Seed는 일치하는 committed full SHA를 고정해요. 일치하는 버전을 확인할 수 없으면 전문으로 전환해요.
- 이슈는 저장소·번호·관측한 `updatedAt`을 적고 시작할 때 body/state/version을 재확인해요.
- 현재 metadata 자격·버전 확인 뒤 요구 원문과 기준 이후 변경을 대화에 출력해요.
  변경·조회 실패·부적격은 요구 적용을 보류해 확인받아요. 과거 SHA가 현재 요구 적용의 승인은 아니에요.
- 검사 명령·독립 요구사항 리뷰/base/라운드 상한·미충족 시 미완료·턴 상한·보호/권한 제한은 목표에 남겨요.
- Claude의 읽기용 박스와 복사용 목표를 분리해요. 긴 목표는 `/goal `을 먼저 입력하고 본문만 붙여요.
  Codex는 평문 필드와 plain `GOAL`을 유지해요.

## 실제 입력 실측

Claude Code **2.1.300**, 80열 PTY, 빈 임시 폴더, safe mode, 도구 비활성·plan mode에서
터미널 bracketed-paste 이벤트를 보냈어요. 사용자에게 수동 실측을 먼저 요구하지 않았어요.
각 경로는 1회 관찰이며 같은 시도의 재실행으로 성공률을 추정하지 않았어요.

| 경로 | 관찰 |
|---|---|
| 짧은 332자 포인터 형태 명령 전체 붙여넣기 | 접히지 않았고 `Goal set:` 및 `goal_status`가 기록됐어요. |
| 긴 1,679자 명령 전체 붙여넣기 | `[Pasted text #1]`로 접혔고, transcript에 `/goal`을 포함한 `<pasted_content …>` 일반 user 메시지로 기록됐어요. native 명령으로 등록되지 않았어요. |

| 대화형 CLI의 시작 프롬프트 `/goal …` | `Goal set:` 및 active 표시가 기록됐어요. 기본 전달 경로를 이 방식으로 바꾸지는 않았어요. |

첫 세 경로의 session id는 `32cb6b86-8b2f-40a3-9c3b-23da8f88baee`, 시작 프롬프트 경로는
`862f43c0-d72b-4140-8ee4-c2beed90f00f`예요. 검사 세션의 goal을 해제하거나 achieved를 확인하고
두 프로세스를 종료했어요. 포인터 형태 입력은 명령 인식을 확인한 예시이며, 그 예시의 가짜 Seed나
검사·리뷰 조건이 실제 충족됐다는 뜻이 아니에요. evaluator가 예시의 여러 조건을 실제 요구로 해석했으므로
이를 완료 품질 증거로 쓰지 않아요.

관측 길이는 범용 접힘 임계값이 아니에요. OS 클립보드, 사용자의 실제 터미널 설정, 다른 CLI 버전에서의
붙여넣기까지 증명하지 않아요. [공식 goal 문서](https://code.claude.com/docs/en/goal)는 대화에 노출된
증거만으로 평가하고 조건은 최대 4,000자라고 설명해요. 이번 변경도 그 계약을 유지해요.

## 구현·검증 범위

- renderer는 기본/Codex 출력을 보존하고 `--runtime claude`에만 80셀 박스를 적용해요.
  한글·전각 2셀, 결합 문자 0셀, 모호 폭 1셀을 기준으로 줄바꿈과 걸이 들여쓰기를 처리해요.
  연속 ID만 압축하고 정상 TRACE를 줄여요. 중단·실패·외부·미확인·변경 경고는 보존해요.
- Seed board는 실제 박스 헤더를 성공 출력으로 수집해요. 거절·오류·출력 누락은 수집하지 않아요.
- session-close 소스도 표시를 그대로 배치하고, 긴 전문의 입력 안내를 첫 보고 블록에 놓도록 맞췄어요.
- Python renderer 회귀, mod 41개 테스트, session-close 어댑터·정책 린트가 통과했어요.
  tiktoken 예산 검사에서 19개 description 합계 7,312자, next-goal 본문은 7,979바이트예요.
  source gate 검사는 실제 모델 준수를 보장하지 않아요.

독립 요구사항·정확성 리뷰는 1회 실시했어요. P0/P1은 없었고, 한글 결합 성조점
`〮`·`〯`가 행 경계에서 분리되는 P2 1건을 수정했어요. 이 문자는 `Mc`이지만 canonical
combining class가 있으므로 0셀로 계산하도록 보완했어요. 수정 전 두 입력은 분리되고
수정 후 같은 행에 남는 것을 직접 비교했으며, public renderer 경계 회귀도 통과했어요.
추가 독립 리뷰 라운드는 실행하지 않았어요.

별도 소스 지침 시뮬레이션은 committed Seed·이슈·원본 없는 후속·dirty Seed 네 입력을 비교했어요.
원문 없는 dirty Seed에 임의 SHA나 요구를 만들지 않는 fallback을 확인했고, 목표에 절차를 길게
재서술하는 경향이 있어 필드 배치 표와 짧은 절 예시를 보완했어요. 설치본 스킬 호출 증거로 세지 않아요.

사용자 설치본의 새 스킬 discovery/invocation, 실제 OS 클립보드 경로, 모호 폭을 넓게 쓰는 터미널의
테두리 정렬, 실제 앱에서의 시각적 렌더링은 미검증이에요. 이 기록은 설치 반영 전 소스 검증과
입력 프로브의 근거이며, 이후 커밋·게시 상태와 두 저장소의 연결은 각 PR 설명에서 확인해요.
